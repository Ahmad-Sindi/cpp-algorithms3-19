# Algorithm Challenge #19 – Min & Max Number in Matrix (Level 3)

🧮 **Problem Description**
-
This program finds the **minimum** and **maximum** values inside a 3×3 matrix.

The algorithm scans the entire matrix while maintaining two variables
that track the smallest and largest values encountered.

---

💡 **What You’ll Learn**
-
- Traversing a matrix to aggregate information
- Tracking state while iterating through data
- Applying comparison-based logic efficiently
- Understanding matrices as bounded numeric spaces
- Writing clean and readable helper functions

---

🧩 **Example**
-
**Matrix:**

100 77 90

5 24 62

85 2 14


**Output:**

Min Number In Matrix: 2

Max Number In Matrix: 100

💬 **Notes**
-
This challenge is closely related to other matrix traversal problems (searching, counting, and intersection).

The key difference is that this algorithm focuses on **aggregation** — extracting global properties from a data structure rather than checking for existence or relationships.
